## Agent skills

### Issue tracker

Track issues and specs in GitHub Issues for `himansu9805/wingman-harness`. Use `gh` to read, create, and update issues. Use native GitHub sub-issues and dependencies for parent links and blockers. Pull requests are excluded from the triage queue.

### Triage labels

Use `needs-triage` for issues awaiting review, `needs-info` for issues awaiting clarification, `ready-for-agent` for fully specified agent work, `ready-for-human` for work requiring human implementation, and `wontfix` for issues the project will decline.

### Domain docs

Wingman uses one shared domain vocabulary across core, server, CLI, and web. Read the [Glossary](https://github.com/himansu9805/wingman-harness/wiki/Glossary) and relevant decisions from the [ADR Index](https://github.com/himansu9805/wingman-harness/wiki/ADR-Index) before domain work. Use the glossary’s terms in issues, specs, and tests. Flag conflicts with existing decisions. If a page doesn’t exist yet, continue and add entries when terms or decisions are agreed.
